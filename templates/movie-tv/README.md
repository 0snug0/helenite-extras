# Movies & TV vault template

A Helenite vault template for a film and TV diary. New vault → **From a template** → this repository's git URL.

What you get:

- **Notes from your diaries.** Python scripts sync Letterboxd (films) and Serializd (TV) into one note per film or show, with every watch, rating and review, the watchlist, cast and crew, and Letterboxd / Rotten Tomatoes scores. Person notes appear for people in two or more of your films.
- **Home app.** Stats, last watched, a calendar and year charts, daily picks and a New & Upcoming row.
- **Downloadrr and Downloadrr TV apps.** Your watchlist and pending films and shows with Radarr / Sonarr status, SABnzbd progress, Plex watch state and a release picker.
- **Background jobs.** launchd agents for the daily sync, the watchlist, Serializd and the weekly releases (macOS).

The vault's setup agent follows `setup/SETUP.md`: it asks for your usernames and services, runs the first sync and installs the apps. You enter API keys yourself.

## Requirements

- Helenite 0.1.0 or later
- python3 (3.9+), and a TMDB v4 read access token
- Optional: Radarr, Sonarr, SABnzbd, Plex

## Maintaining this template

The template lives in the Helenite repository at `templates/movie-tv/`. `Apps/`, `setup/helenite/`, the scripts, views, Bases and launchd agents are generated by `node scripts/sync-movie-tv-template.mjs` (run it from the Helenite repository) from `ports/eric/apps` and an Obsidian vault, with personal values rewritten; `--check` reports drift. Everything else is written by hand. To publish it, push this folder as its own git repository.
